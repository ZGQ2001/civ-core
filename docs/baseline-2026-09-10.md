- MCP 冒烟遇到 `isError` 会失败退出；临时预设使用唯一名称，避免与用户已有预设撞名。

- Vite 忽略 `src-tauri` 目录，修复监听 Rust 产物时的 Windows `EBUSY` 启动失败。配置依据：[Tauri 官方 Vite 指南](https://v2.tauri.app/zh-cn/start/frontend/vite/)。

## 完整链路验证

在依赖已还原、C# 和 MCP 已编译后，于仓库根运行：

```bash
node mcp/scripts/pipeline-smoke.mjs
```

也可传入一个尚不存在的输出目录；脚本拒绝覆盖已有目录。失败返回非零退出码，`evidence.json` 保存各步骤响应及最终状态。

验证路径：MCP 客户端 → MCP 服务 → C#/Python sidecar → 锚杆结果 Excel → PNG 曲线 → 防火涂层结果 Excel → 混合 Word 报告。

- 锚杆样例：3 根、1 根合格、2 根不合格；首根弹性位移 `2.63 - 0.58 = 2.05mm`。
- Excel 保留判定依据 sheet 和可取消隐藏的 `_批次参数` sheet。
- 3 张 PNG 文件格式正确，已人工查看首根曲线的中文标注和加载/卸载路径。
- 防火涂层：2 个样例构件，填入合成测点后均判为合格。
- 混合 Word：5 张表、3 张嵌图；项目名完成填充，无残留占位符、未知字段或缺失图片。
- Word 模板使用中文占位符，`user_inputs` 使用 catalog 的规范字段键，例如 `project_name`。

本轮未推送，因此这些 CI 作业尚未在 GitHub 上执行；表中结果均为本机实跑。
